About

Welcome to Tech Fix Notes!

My name is Aizen, and I write simple, step-by-step solutions to the computer problems people run into every day.

Here you will find guides on:

  • Printer problems and driver installation
  • Windows and PC troubleshooting
  • Excel tutorials and formulas
  • LAN, WiFi and internet connection issues

Every guide is written in plain language so you can follow along without a technical background. I explain what is happening, show the quickest fix first, and tell you when it is time to call a technician instead.

How the guides are written

Each guide starts with the most common cause and the easiest fix, then moves to deeper steps. Software menus and printer models differ, so if something on your screen looks different, tell me and I will update the guide.

Need help with a problem?
